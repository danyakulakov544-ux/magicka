# 4D — карта и стол

Визуальный прототип двух пространств. Правил фракций и рогалика ещё нет: здесь камера, свет и то, как фишка и карты двигаются.

Старая арена магов осталась в `scenes/battle`, в меню её нет.

## Как скачать и запустить

Играть можно без Godot. Сборка для Windows:

https://github.com/danyakulakov544-ux/magicka/releases/download/latest/4D-windows.zip

Скачайте архив, распакуйте и запустите `4D.exe`. Это один файл. Ссылка одна и та же: сборка заменяется при пуше в `main` и в ветки прототипа. Если Windows пишет, что издатель неизвестен, нажмите «Подробнее», затем «Выполнить в любом случае».

Сборка для Linux: https://github.com/danyakulakov544-ux/magicka/releases/download/latest/4D-linux.zip — после распаковки выполните `chmod +x 4D.x86_64`.

## Как открыть в редакторе

Нужен **Godot 4.7.2** (обычная сборка, не .NET): [godotengine.org/download](https://godotengine.org/download/).

1. Распакуйте Godot. Установщик не нужен.
2. В окне Godot нажмите **Import**, укажите `project.godot` и подтвердите.
3. Нажмите **F5**.

Откроется меню. Рендер — Compatibility (OpenGL).

## Меню

| Кнопка | Куда ведёт |
| --- | --- |
| Карта | пиксельное поле с узлами |
| Стол | карточный стол сразу, без карты |

## Карта

Поле как в настолке: узлы и линии между ними. Четыре фишки стоят на старте. Выбранная — первая, синяя.

| Действие | Управление |
| --- | --- |
| Выбрать фишку | клавиши 1 2 3 4 или клик по фишке |
| Ход | клик по соседнему узлу. Фишка идёт по линии |
| Бой, элита, босс | после хода открывается стол. Колода — цвет выбранной фишки |
| Меню | Esc или «В меню» |

Яркая линия — куда можно пойти с места выбранной фишки. Подсказка у курсора называет узел.

## Стол

Вид от первого лица: тёмная комната, деревянный стол, лампа и свечи. В руке карты выбранной колоды (маги, короли, мертвецы или звери — цвет рамки). На столе три ряда по четыре слота: ближний ваш, средний и дальний — сторона противника. Справа две стопки рубашкой вверх. Слева весы и гонг.

| Действие | Управление |
| --- | --- |
| Взять карту | наведите на карту в руке и зажмите левую кнопку |
| Положить | отпустите над свободным слотом своего ряда. Карта летит дугой |
| Вернуть в руку | отпустите мимо слота |
| Добор | клик по большой колоде справа |
| Гонг | Пробел или клик по гонгу. Ваши карты на столе бьют слева направо |
| Взгляд вперёд, на противника | W, удерживать |
| Взгляд вниз, на руку | S, удерживать |
| Взгляд влево / вправо | A / D, удерживать |
| Назад | Esc. Если пришли с карты, вернётесь на неё с теми же фишками. Иначе — в меню |

Цифры на карте: стоимость справа сверху, атака слева снизу, здоровье справа снизу. Это заглушки, не правила.
