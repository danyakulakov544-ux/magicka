# Magicka — прототип арены

Первый играбельный кусок будущей игры: боевая арена в 3D. Общая карта, по которой фишки ходят как в настольной игре, будет отдельной задачей. Сети и выбывания ещё нет.

## Как скачать и запустить

Играть можно без Godot. Сборка для Windows:

https://github.com/danyakulakov544-ux/magicka/releases/download/latest/MagickaArena-windows.zip

Скачайте архив, распакуйте и запустите `MagickaArena.exe`. Это один файл, рядом ничего класть не нужно. Ссылка одна и та же: сборка заменяется при каждом пуше в `main` и в ветку прототипа. Если Windows пишет, что издатель неизвестен, нажмите «Подробнее», затем «Выполнить в любом случае».

Сборка для Linux: https://github.com/danyakulakov544-ux/magicka/releases/download/latest/MagickaArena-linux.zip — после распаковки выполните `chmod +x MagickaArena.x86_64`.

## Как открыть в редакторе

Редактор нужен только тем, кто меняет игру. Это **Godot 4.7.2** (стабильная ветка 4.x). Сборки редактора: [godotengine.org/download](https://godotengine.org/download/). Берите обычную версию, не .NET.

1. Скачайте и распакуйте Godot 4.7.2. Установщик не нужен: это один исполняемый файл.
2. В окне Godot нажмите **Import**, укажите `project.godot` в корне репозитория и подтвердите импорт.
3. Откроется проект. Нажмите **F5** (или кнопку Play в правом верхнем углу).

Главная сцена — `scenes/battle/battle_arena.tscn`. Это 3D-арена: камера сверху под углом, как в Magicka, и плавно следует за магами. Рендер — Compatibility (OpenGL), чтобы сборка шла и на слабых видеокартах.

Вы играете синим магом. Красный — простой бот: он подходит и кастует сам. Клавиши читаются по физическому положению, как на QWERTY. Русская раскладка не мешает: «Q» — это клавиша «Й», «W» — «Ц», и так далее.

Самоиграйка без участия людей (для проверки картинки):

```bash
godot --path . -- --demo
```

Проверка правил и боя без окна:

```bash
godot --headless --path . -s res://scripts/tests/run_tests.gd
```

## Управление

Игрок один, второй маг — бот. Мышь указывает точку на полу, маг к ней поворачивается. Ходьба — WASD относительно камеры, поэтому вода больше не на W.

| Действие | Клавиша |
| --- | --- |
| Ходьба | W A S D |
| Прицел | движение мыши |
| Огонь | Q или 1 |
| Вода | Z или 2 |
| Молния | E или 3 |
| Земля | R или 4 |
| Жизнь | F или 5 |
| Каст в противника | левая кнопка мыши |
| Каст на себя | правая кнопка мыши |
| Сбросить очередь | C |
| Новый раунд после конца боя | Enter |

## Как кастуется магия

В очереди не больше трёх сфер. Над каждым магом висят полоски здоровья и щита и цветные сферы очереди. На экране дублируется то же самое и имя заклинания.

Порядок набора не важен: `огонь + земля` и `земля + огонь` — одна и та же магма. Перед поиском заклинания противоположные сферы снимаются парами:

- огонь гасит воду, вода гасит огонь;
- молния гасит землю, земля гасит молнию;
- жизнь ничем не гасится.

Примеры: `огонь + вода` сгорает вхолостую («Сферы погасли»). `огонь + огонь + вода` оставляет один огонь и кидает обычный огненный шар. `молния + земля + жизнь` оставляет жизнь.

Каст в противника и каст на себя — разные заклинания одной и той же связки. Огонь на себя обжигает вас. Жизнь на себя лечит слабо: одна сфера восстанавливает 12, три сферы — 28. Щит из земли и жизни — 24. Остальные свои лечения и щиты примерно вдвое меньше прежних чисел. Щит тратится раньше здоровья, потолок щита — 80. Здоровье — 100. Часть водяных связок ещё и замедляет.

Пауза после каста задаётся в `rules` файла `data/spells.json`: 0,25 с плюс 0,15 с за каждую сферу в очереди. Одна сфера — 0,4 с, две — 0,55 с, три — 0,7 с. Считаются набранные сферы, даже если часть погасла. Если среди эффектов есть лечение, пауза умножается на 2,5: одна сфера жизни держит 1 с. Обычный размен убивает примерно за 2–3 секунды, и лечение это не отменяет.

Луч примерно на четверть слабее снаряда того же размера. В таблице у лучей уже окончательный урон: игра сама его не уменьшает, замаха перед лучом нет.

Свои снаряды и лучи не задевают кастера. Область бьёт по противнику, если он в круге взрыва или стоит на пути от вас до центра взрыва. Каст на себя бьёт только вас.

Если связки нет в таблице, выходит «Сырая магия»: слабый снаряд, урон растёт с числом сфер. Так новая смесь не молчит, пока для неё не придумают имя.

Все числа и имена лежат в одном файле: `data/spells.json`.

## Как добавить стихию или связку

Правила боя — только `data/spells.json`. Клавиши новой стихии прописываются рядом, в `scripts/battle/local_hotseat.gd` (словарь `BINDINGS`): игра не угадывает, какая клавиша свободна.

### Новая стихия

В объект `elements` добавьте запись. `opposites` — список id тех, кого она гасит. Противоположность лучше указать с обеих сторон.

```json
"arcane": {
  "name": "Тайная",
  "letter": "Т",
  "color": "#b06bff",
  "opposites": []
}
```

В `local_hotseat.gd` выдайте ей клавишу у каждого мага, например `KEY_T: "arcane"` и `KEY_Y: "arcane"`.

### Новая связка

В массив `spells` добавьте объект. Поле `elements` — какие сферы нужны и в каком количестве. `fire` один раз — одна сфера, три раза — три. Id удобно делать из id стихий через `+`, в алфавитном порядке: так устроен ключ поиска.

```json
{
  "id": "arcane+fire",
  "elements": ["arcane", "fire"],
  "casts": {
    "foe": {
      "name": "Чародейское пламя",
      "delivery": "projectile",
      "speed": 280,
      "radius": 6,
      "effects": [{ "kind": "damage", "amount": 20 }]
    },
    "self": {
      "name": "Чародейское пламя",
      "delivery": "instant",
      "effects": [{ "kind": "damage", "amount": 16 }]
    }
  }
}
```

`delivery`:

- `projectile` — летит вперёд. Имеют смысл `speed` и `radius`.
- `beam` — короткий луч. Имеет смысл `length` (дальность в пикселях).
- `area` — круг. `offset` — насколько впереди вас центр, `radius` — размер.
- `instant` — сразу, без снаряда. Для каста на себя это обычный выбор.

`effects` — список. `kind`: `damage`, `heal`, `shield` (число в `amount`) или `slow` (`amount` — доля скорости, например `0.5`, `duration` — секунды). Эффекты применяются по порядку. Если удар уронил здоровье до нуля, остаток связки уже не лечит.

Если описать только `foe`, каст на себя применит те же эффекты мгновенно к вам. Если описать только `self`, каст в противника выпустит снаряд с теми же эффектами.

Необязательные поля и их значения по умолчанию: `speed` 240, `length` 180, `radius` 5 у снаряда и 36 у области, `offset` 64 у области, время жизни снаряда 3 секунды. Свой `color` в виде `#rrggbb` перекрывает смесь цветов стихий.

Связка, в которой уже есть пара противоположностей, не сработает никогда: пары снимаются раньше поиска. `огонь + вода + тайная` — это просто тайная магия.

Общие числа (здоровье, щит, скорость, длина очереди, пауза между кастами) — в объекте `rules` того же файла.

## Стихии

| Id | Имя | Клавиши | Гасит |
| --- | --- | --- | --- |
| `fire` | Огонь | Q / U | воду |
| `water` | Вода | W / I | огонь |
| `lightning` | Молния | E / O | землю |
| `earth` | Земля | R / P | молнию |
| `life` | Жизнь | F / H | никого |

Жизнь — пятая стихия. Щит из неё не кастуется сам по себе: щит дают связки земли и жизни (каст на себя).

## Как устроен код и куда встанет сеть

Бой меняется только через команды. Клавиатура этого не делает.

- `scripts/battle/local_hotseat.gd` читает клавиши и мышь игрока и шлёт `BattleCommand`. `scripts/battle/bot.gd` делает то же за второго мага.
- `scripts/net/battle_command.gd` — сама команда: слот, действие, сфера, направление, каст на себя. `to_dict()` / `from_dict()` уже годятся для RPC.
- `scripts/battle/battle_arena.gd` — `apply_command()`. Здесь очередь, каст, урон, конец раунда и рестарт.
- `scripts/data/spellbook.gd` читает `data/spells.json` и ничего не знает про узлы сцены.
- `scripts/autoload/match_session.gd` помнит, чей какой слот. Сейчас режим `local_hotseat`, оба слота местные.

Дальше сеть — это Godot high-level multiplayer поверх ENet, без переделки магов:

1. Хост: `ENetMultiplayerPeer.create_server(port)`.
2. Клиент: `create_client(ip, port)`.
3. В `MatchSession.slot_owner` записать peer id владельца слота, режим сменить на `enet_host` или `enet_client`.
4. Клиент шлёт на хост тот же словарь, что даёт `BattleCommand.to_dict()`.
5. Хост вызывает `apply_command()` и рассылает команду остальным.

Маги, снаряды и интерфейс по-прежнему не читают `Input`. Движение — это тоже команда с направлением, а не чужая запись в координаты. Позиции и здоровье можно будет подтверждать на хосте.

Шрифт интерфейса — Noto Sans (SIL Open Font License 1.1), файл `fonts/NotoSans-Regular.ttf`. Текст лицензии лежит рядом.

## Дорожная карта

1. **Сетевой бой 1 на 1.** Хост и клиент по IP через ENet. Каждый за своим компьютером, в том числе через Tailscale. Команды уже отделены от ввода.
2. **Общая карта.** Отдельный 2D-слой: фишки на поле, как в настольной игре. Тропы, бои с ботами, таверны, сферы стихий. Арена этого прототипа — уже 3D и сюда подключается позже.
3. **Переход карта → арена.** Встреча двух игроков открывает эту арену. Победитель возвращается на карту, проигравший — нет.
4. **Стадии и выбывание.** Стадия поджимает карту или чаще сводит игроков. Кто проиграл бой — выбывает. Последний живой забирает матч.
